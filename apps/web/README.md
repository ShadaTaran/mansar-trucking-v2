# @mansar/web

Admin web application for the Mansar Trucking Management System v2, built
with Next.js (App Router).

Scaffold stage only: the app renders a single development page that proves
the workspace wiring. Application screens, authentication, and API
integration arrive in later stages.

## Commands

Run from the repository root with `-w @mansar/web`, or from this directory.

| Command             | What it does                             |
| ------------------- | ---------------------------------------- |
| `npm run dev`       | Development server (default port `3000`) |
| `npm run build`     | Production build to `.next/`             |
| `npm run start`     | Serve the production build               |
| `npm run typecheck` | `next typegen` then `tsc --noEmit`       |
| `npm run lint`      | ESLint (root flat config + Next rules)   |
| `npm run test`      | Vitest + React Testing Library (jsdom)   |

Scripts that compile or run the app (`dev`, `build`, `typecheck`, `test`,
`test:watch`) first run `build:deps`, which builds the `@mansar/types`
workspace package this app consumes. Installation never generates that
output.

`next-env.d.ts` is generated by Next.js and intentionally not committed.
